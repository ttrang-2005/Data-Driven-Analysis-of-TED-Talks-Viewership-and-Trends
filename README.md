### 📌 Overview
This project explores TED Talks datasets (1984–2017) to uncover trends in audience engagement, speaker influence, and content popularity. The analysis provides insights and recommendations for optimizing TED’s content strategy.

### 🧩 Objectives
- Analyze viewership trends, topic distributions, and audience behavior.  
- Identify factors influencing TED Talk popularity.  
- Provide actionable insights for content producers and speakers.

### 🧮 Techniques & Tools
- **Data Source:** TED Talks dataset (1984–2017)  
- **Technologies:** Python, Pandas, Matplotlib, Seaborn, Excel  
- **Analysis Areas:** Topic trends, view counts, speaker impact, duration effects  

### 🚀 Key Achievements
- Found that **speaker popularity** and **10–20 minute durations** drive higher engagement.  
- Identified consistent interest in culture, business, and technology topics.  
- Revealed evolving audience behavior patterns over time.  
- Proposed recommendations for enhancing TED’s viewer retention and content strategy.
